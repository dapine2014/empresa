# Aria v1 — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que toda misión del Development Group parta de requisitos (roles, HU, escenarios, incrementos) escritos por Aria y aprobados por el fundador, y que Neo y el equipo construyan solo el incremento aprobado.

**Architecture:** piezas puras nuevas (`RequirementsSpec`, `RequirementsSpecValidator`, `RequirementsText`) y un servicio `RequirementsWriter` (Aria, mismo patrón de reintentos que `TeamWorkPlanner`) con su persistencia `RequirementsMemoryService`. `MissionExecutor` pausa la misión en `AWAITING_SPEC_APPROVAL` tras Aria (setter opcional: sin writer, todo como hoy) y la reanuda al aprobar o al construir un incremento. El bloque del incremento se antepone a la instrucción que reciben Neo y el equipo, así llega a todos los prompts sin tocar las estrategias.

**Tech Stack:** Java 21, Spring Boot 4.1.1, Jackson 3 (`tools.jackson.*`), Neo4j (driver plano, Cypher a mano), JUnit 5 + Mockito, React + TS (Command Center).

**Spec:** `docs/superpowers/specs/2026-10-03-aria-v1-design.md`

## Global Constraints

- Rama `aria-v1`. Suites verdes al final de cada tarea: `cd app && mvn test`; la tarea de frontend además `cd app/frontend && npm run lint && npm run build`.
- Jackson 3 (`tools.jackson.*`), sin `@Async`, errores HTTP por `IllegalArgumentException`/`IllegalStateException` sin manejo nuevo.
- Aria es el agente `product-owner`; su tarea es `<misión>-REQUIREMENTS` (versión 1) y `<misión>-REQUIREMENTS-V<n>` (ajustes), `kind` `REQUIREMENTS`, `action` `REQUIREMENTS_SPEC`.
- Ids exactos: `HU-\d{2}`, `ESC-\d{2}`; ≤ 12 escenarios por incremento; hasta 3 intentos de Aria con corrección.
- Estado nuevo `MissionStatus.AWAITING_SPEC_APPROVAL`. Policy nueva `SPEC_APPROVAL_REQUIRED` (0/1, default 1).
- Construir el incremento N no consume `MAX_EVIDENCE_ROUNDS`.
- Eventos nuevos (prefijo `EMPRESA_`): `EMPRESA_REQUIREMENTS_READY`, `EMPRESA_REQUIREMENTS_APPROVED`, `EMPRESA_REQUIREMENTS_ADJUSTED`, `EMPRESA_REQUIREMENTS_REJECTED`, `EMPRESA_INCREMENT_STARTED`.
- Textos para el modelo y el fundador en español; comentarios "Spec 2026-10-03 Aria §n" en el código nuevo.

2. **Aprobar dos veces o decidir sobre una misión que no espera aprobación** (doble clic, chat + botón): la segunda vez se rechaza con el motivo y no lanza otra ejecución. Test en la Task 5.

    }

    }

package com.aicompany.core.agent.validation;

import com.aicompany.core.agent.model.RequirementsSpec;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.regex.Pattern;
import java.util.stream.IntStream;

/** Spec 2026-10-03 Aria §2: reglas de Java sobre el spec de Aria (lista vacía = válido). */
public final class RequirementsSpecValidator {

    public static final int MAX_SCENARIOS_PER_INCREMENT = 12;
    private static final Pattern HU = Pattern.compile("HU-\\d{2}");
    private static final Pattern ESC = Pattern.compile("ESC-\\d{2}");

    private RequirementsSpecValidator() {
    }

    public static List<String> validate(RequirementsSpec spec) {
        var errors = new ArrayList<String>();
        if (spec == null) {
            return List.of("El spec está vacío.");
        }

        var roleNames = new HashSet<String>();
        if (spec.rolesOrEmpty().isEmpty()) {
            errors.add("roles debe listar al menos un rol: quién usa el producto (p. ej. comprador, administrador).");
        }
        for (var role : spec.rolesOrEmpty()) {
            if (role.name() == null || role.name().isBlank()) {
                errors.add("Hay un rol sin nombre.");
            } else if (!roleNames.add(role.name().strip())) {
                errors.add("El rol \"" + role.name() + "\" está repetido.");
            }
        }

        var stories = spec.userStoriesOrEmpty();
        if (stories.isEmpty()) {
            errors.add("userStories debe tener al menos una historia de usuario.");
        }
        var storyIds = new HashSet<String>();
        var scenarioIds = new HashSet<String>();
        for (var story : stories) {
            var id = story.id();
            if (id == null || !HU.matcher(id).matches()) {
                errors.add("El id de historia \"" + id + "\" no tiene el formato HU-01.");
            } else if (!storyIds.add(id)) {
                errors.add("La historia " + id + " está repetida.");
            }
            if (story.role() == null || !roleNames.contains(story.role().strip())) {
                errors.add(id + ": el rol \"" + story.role() + "\" no está en roles " + roleNames + ".");
            }
            if (story.acceptanceCriteriaOrEmpty().stream().allMatch(c -> c == null || c.isBlank())) {
                errors.add(id + " necesita al menos un criterio de aceptación.");
            }
            if (story.scenariosOrEmpty().isEmpty()) {
                errors.add(id + " necesita al menos un escenario (dado / cuando / entonces).");
            }
            for (var scenario : story.scenariosOrEmpty()) {
                var sid = scenario.id();
                if (sid == null || !ESC.matcher(sid).matches()) {
                    errors.add("El id de escenario \"" + sid + "\" de " + id + " no tiene el formato ESC-01.");
                } else if (!scenarioIds.add(sid)) {
                    errors.add("El escenario " + sid + " está repetido: los ids no se reutilizan.");
                }
                if (empty(scenario.given()) || empty(scenario.when()) || empty(scenario.then())) {
                    errors.add(sid + " de " + id + ": given, when y then no pueden estar vacíos.");
                }
            }
        }

        var numbers = spec.incrementNumbers();
        var expected = IntStream.rangeClosed(1, Math.max(1, numbers.size())).boxed().toList();
        if (numbers.isEmpty() || !numbers.equals(expected)) {
            errors.add("Los incrementos van numerados desde 1 sin huecos (" + expected.toString()
                    .replaceAll("[\\[\\]]", "") + "); recibidos " + numbers + ".");
        }
        var incrementOf = new HashMap<String, Integer>();
        var count = new HashMap<String, Integer>();
        for (var increment : spec.incrementsOrEmpty()) {
            for (var id : increment.userStoryIdsOrEmpty()) {
                count.merge(id, 1, Integer::sum);
                incrementOf.put(id, increment.number());
            }
            var scenarios = spec.scenarioCount(increment.number());
            if (scenarios > MAX_SCENARIOS_PER_INCREMENT) {
                errors.add("El incremento " + increment.number() + " tiene " + scenarios + " escenarios: máximo "
                        + MAX_SCENARIOS_PER_INCREMENT + ". Pasa historias a un incremento posterior.");
            }
        }
        for (var id : storyIds) {
            if (count.getOrDefault(id, 0) != 1) {
                errors.add(id + " debe estar en exactamente un incremento (está en " + count.getOrDefault(id, 0) + ").");
            }
        }

        var depsOf = new HashMap<String, List<String>>();
        for (var story : stories) {
            depsOf.put(story.id(), story.dependsOnOrEmpty());
            for (var dep : story.dependsOnOrEmpty()) {
                if (!storyIds.contains(dep)) {
                    errors.add(story.id() + " depende de " + dep + ", que no existe.");
                } else if (incrementOf.containsKey(dep) && incrementOf.containsKey(story.id())
                        && incrementOf.get(dep) > incrementOf.get(story.id())) {
                    errors.add(story.id() + " depende de " + dep + ", que está en un incremento posterior.");
                }
            }
        }
        if (hasCycle(depsOf)) {
            errors.add("Las dependencias entre historias forman un ciclo.");
        }
        return errors;
    }

    private static boolean empty(List<String> steps) {
        return steps == null || steps.stream().allMatch(s -> s == null || s.isBlank());
    }

    private static boolean hasCycle(Map<String, List<String>> deps) {
        var state = new HashMap<String, Integer>();
        for (var node : deps.keySet()) {
            if (visit(node, deps, state)) {
                return true;
            }
        }
        return false;
    }

    /** 1 = en curso, 2 = terminado. */
    private static boolean visit(String node, Map<String, List<String>> deps, Map<String, Integer> state) {
        var s = state.getOrDefault(node, 0);
        if (s == 1) {
            return true;
        }
        if (s == 2) {
            return false;
        }
        state.put(node, 1);
        for (var next : deps.getOrDefault(node, List.of())) {
            if (deps.containsKey(next) && visit(next, deps, state)) {
                return true;
            }
        }
        state.put(node, 2);
        return false;
    }
}

import org.neo4j.driver.Driver;

/** Spec 2026-10-03 Aria §1: versiones del spec de Aria por misión ((:Mission)-[:HAS_REQUIREMENTS]->). */
@Service
public class RequirementsMemoryService {

    public record Version(int version, String specJson, String status, String instruction, Instant createdAt) {
    }

    private final Driver driver;

    public RequirementsMemoryService(Driver driver) {
        this.driver = driver;
    }

    public int saveDraft(String missionId, String specJson, String instruction) {
        try (var session = driver.session()) {
            return session.executeWrite(tx -> {
                var next = tx.run("MATCH (m:Mission {id:$id}) OPTIONAL MATCH (m)-[:HAS_REQUIREMENTS]->(r) "
                        + "RETURN coalesce(max(r.version), 0) + 1 AS v", Map.of("id", missionId)).single().get("v").asInt();
                tx.run("MATCH (:Mission {id:$id})-[:HAS_REQUIREMENTS]->(r:RequirementsVersion {status:'DRAFT'}) "
                        + "SET r.status = 'SUPERSEDED'", Map.of("id", missionId));
                tx.run("MATCH (m:Mission {id:$id}) CREATE (m)-[:HAS_REQUIREMENTS]->(:RequirementsVersion {version:$v, "
                                + "specJson:$spec, status:'DRAFT', instruction:$instruction, createdAt:datetime()})",
                        Map.of("id", missionId, "v", next, "spec", specJson,
                                "instruction", instruction == null ? "" : instruction));
                return next;
            });
        }
    }

    public Optional<Version> latest(String missionId) {
        return query(missionId, "");
    }

    public Optional<Version> approved(String missionId) {
        return query(missionId, " AND r.status = 'APPROVED'");
    }

    private Optional<Version> query(String missionId, String filter) {
        try (var session = driver.session()) {
            return session.run("MATCH (:Mission {id:$id})-[:HAS_REQUIREMENTS]->(r:RequirementsVersion) WHERE true" + filter
                            + " RETURN r.version AS v, r.specJson AS s, r.status AS st, r.instruction AS i, "
                            + "toString(r.createdAt) AS c ORDER BY r.version DESC LIMIT 1", Map.of("id", missionId))
                    .list(r -> new Version(r.get("v").asInt(), r.get("s").asString(), r.get("st").asString(),
                            r.get("i").isNull() ? "" : r.get("i").asString(),
                            r.get("c").isNull() ? null : java.time.OffsetDateTime.parse(r.get("c").asString()).toInstant()))
                    .stream().findFirst();
        }
    }

    public void approve(String missionId, int version, String approvedBy) {
        write("MATCH (m:Mission {id:$id})-[:HAS_REQUIREMENTS]->(r:RequirementsVersion {version:$v}) "
                + "SET r.status='APPROVED', r.approvedBy=$by, r.approvedAt=datetime(), m.approvedSpecVersion=$v",
                Map.of("id", missionId, "v", version, "by", approvedBy));
    }

    public void reject(String missionId, int version) {
        write("MATCH (:Mission {id:$id})-[:HAS_REQUIREMENTS]->(r:RequirementsVersion {version:$v}) SET r.status='REJECTED'",
                Map.of("id", missionId, "v", version));
    }

    public int builtIncrement(String missionId) {
        return intProperty(missionId, "builtIncrement");
    }

    public void setBuiltIncrement(String missionId, int increment) {
        write("MATCH (m:Mission {id:$id}) SET m.builtIncrement=$n", Map.of("id", missionId, "n", increment));
    }

    public int incrementRounds(String missionId) {
        return intProperty(missionId, "incrementRounds");
    }

    public void addIncrementRound(String missionId) {
        write("MATCH (m:Mission {id:$id}) SET m.incrementRounds = coalesce(m.incrementRounds, 0) + 1",
                Map.of("id", missionId));
    }

    private int intProperty(String missionId, String property) {
        try (var session = driver.session()) {
            return session.run("MATCH (m:Mission {id:$id}) RETURN coalesce(m." + property + ", 0) AS n",
                    Map.of("id", missionId)).list(r -> r.get("n").asInt()).stream().findFirst().orElse(0);
        }
    }

    private void write(String cypher, Map<String, Object> params) {
        try (var session = driver.session()) {
            session.executeWrite(tx -> {
                tx.run(cypher, params);
                return null;
            });
        }
    }

import com.aicompany.core.agent.model.RequirementsSpec;
import com.aicompany.core.agent.validation.RequirementsSpecValidator;
import com.aicompany.core.event.CompanyEventPublisher;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import tools.jackson.databind.json.JsonMapper;

import java.util.Map;
import java.util.Optional;

/**
 * Spec 2026-10-03 Aria §1-§2: Aria (Product Owner) convierte el pedido en requisitos; Java los valida
 * (RequirementsSpecValidator) y ella corrige con el motivo exacto, hasta 3 intentos. Cada spec válido es una versión.
 */
@Service
public class RequirementsWriter {

    private static final Logger log = LoggerFactory.getLogger(RequirementsWriter.class);
    public static final String ARIA = "product-owner";
    static final int MAX_ATTEMPTS = 3;

    public record Written(int version, RequirementsSpec spec) {
    }

    private final CeoService ceo;
    private final MissionMemoryService missions;
    private final RequirementsMemoryService requirements;
    private final CompanyMemoryService company;
    private final PromptMemoryService prompts;
    private final CompanyEventPublisher events;
    private final JsonMapper json;
    private final String defaultModel;

    public RequirementsWriter(CeoService ceo, MissionMemoryService missions, RequirementsMemoryService requirements,
                              CompanyMemoryService company, PromptMemoryService prompts, CompanyEventPublisher events,
                              JsonMapper json, @Value("${ollama.agent-model}") String defaultModel) {
        this.ceo = ceo;
        this.missions = missions;
        this.requirements = requirements;
        this.company = company;
        this.prompts = prompts;
        this.events = events;
        this.json = json;
        this.defaultModel = defaultModel;
    }

    public Written write(String missionId, String instruction, Optional<RequirementsSpec> previous, String adjustment) {
        var nextVersion = requirements.latest(missionId).map(v -> v.version() + 1).orElse(1);
        var taskId = missionId + "-REQUIREMENTS" + (nextVersion > 1 ? "-V" + nextVersion : "");
        missions.createTask(taskId, missionId, ARIA, "REQUIREMENTS_SPEC", "REQUIREMENTS");
        missions.updateTask(taskId, "RUNNING", "Aria está escribiendo los requisitos.");
        missions.setAgentStatus(ARIA, "WORKING");
        try {
            var model = company.agentModel(ARIA, defaultModel);
            var agentPrompt = prompts.activePrompt(ARIA);
            var base = prompt(instruction, previous, adjustment);
            String feedback = null;
            for (int attempt = 1; attempt <= MAX_ATTEMPTS; attempt++) {
                var prompt = feedback == null ? base : base + """

                        CORRECCIÓN DEL INTENTO ANTERIOR (Java rechazó el spec por esto; corrígelo todo):
                        %s
                        """.formatted(feedback);
                RequirementsSpec spec;
                try {
                    spec = ceo.writeRequirements(ARIA, prompt, agentPrompt, model);
                } catch (Exception ex) {
                    feedback = "- " + (ex.getMessage() == null ? "Respuesta no procesable." : ex.getMessage());
                    continue;
                }
                var errors = RequirementsSpecValidator.validate(spec);
                if (errors.isEmpty()) {
                    var specJson = json.writeValueAsString(spec);
                    var version = requirements.saveDraft(missionId, specJson, adjustment);
                    missions.updateTask(taskId, "COMPLETED", specJson);
                    log.info("MISSION {} - requirements v{} accepted stories={}", missionId, version,
                            spec.userStoriesOrEmpty().size());
                    return new Written(version, spec);
                }
                feedback = "- " + String.join("\n- ", errors);
                log.warn("MISSION {} - requirements rejected attempt={} errors={}", missionId, attempt, feedback);
            }
            var message = "Aria no produjo requisitos válidos después de " + MAX_ATTEMPTS + " intentos:\n" + feedback;
            missions.updateTask(taskId, "FAILED", message);
            throw new IllegalStateException(message);
        } finally {
            missions.setAgentStatus(ARIA, "IDLE");
        }
    }

    private String prompt(String instruction, Optional<RequirementsSpec> previous, String adjustment) {
        var base = """
                Eres Aria, Product Owner del Development Group de Forjai. Decides QUÉ se construye, nunca CÓMO
                (tecnología, arquitectura y código son del equipo). Convierte el pedido del fundador en requisitos.

                PEDIDO DEL FUNDADOR:
                %s

                REGLAS:
                - roles: quién usa el producto (p. ej. comprador, administrador, paciente, jugador, sistema externo),
                  cada uno con name y description. Cada historia usa uno de esos roles en "role".
                - userStories: HU-01, HU-02… con iWant, soThat, acceptanceCriteria (verificables) y scenarios ESC-01,
                  ESC-02… (ids únicos en todo el spec) con given/when/then concretos: cada escenario será un test.
                - increments: el 1 es el MVP (lo mínimo que funciona de punta a punta), los siguientes ordenan el resto;
                  cada historia en exactamente un incremento; máximo 12 escenarios por incremento; una historia solo
                  depende (dependsOn) de historias de su incremento o de uno anterior.
                - assumptions: cada ambigüedad del pedido y cómo la resolviste. outOfScope: lo que dejas afuera a
                  propósito. No inventes requisitos: lo que agregues va como supuesto.
                - Español, frases cortas.
                """.formatted(instruction);
        if (previous.isEmpty()) {
            return base;
        }
        return base + """

                VERSIÓN ANTERIOR (el fundador pidió un ajuste; conserva lo que no contradiga el ajuste):
                %s

                AJUSTE DEL FUNDADOR:
                %s
                """.formatted(json.writeValueAsString(previous.get()), adjustment == null ? "" : adjustment);
    }

                var mode = TeamExecutionMode.forTeamType(TeamMemoryService.teamType(teamId).orElseThrow());

                safeFail(missionId, ex);
            }

    public Optional<RequirementsView> requirements(String missionId) {
        if (requirementsMemory == null) {
            return Optional.empty();
        }
        var mission = memory.find(missionId);
        if (mission.isEmpty()) {
            return Optional.empty();
        }
        var latest = requirementsMemory.latest(missionId);

    public RequirementsView decideRequirements(String missionId, RequirementsDecisionCommand command) {
        var mission = memory.find(missionId)
                .orElseThrow(() -> new IllegalArgumentException("No existe la misión " + missionId));
        if (mission.status() != MissionStatus.AWAITING_SPEC_APPROVAL) {
            throw new IllegalStateException("MISSION " + missionId + " no está esperando la aprobación de requisitos "
                    + "(estado actual: " + mission.status() + ").");
        }
        var version = requirementsMemory.latest(missionId)
                .orElseThrow(() -> new IllegalStateException("MISSION " + missionId + " no tiene requisitos."));
        if (!"DRAFT".equals(version.status())) {
            // Review Focus 2: el hilo todavía no cambió el estado de la misión; la versión ya decidida lo delata.
            throw new IllegalStateException("La versión " + version.version() + " de los requisitos de " + missionId
                    + " ya está " + version.status() + ".");
        }
        switch (command.decision()) {
            case APPROVE -> {
                requirementsMemory.approve(missionId, version.version(), "founder");
                events.publish("EMPRESA_REQUIREMENTS_APPROVED", missionId, null, "human", Map.of("version", version.version()));
                executor.continueAfterApprovalAsync(missionId);
            }
            case ADJUST -> {
                if (command.instruction() == null || command.instruction().isBlank()) {
                    throw new IllegalArgumentException("Para ajustar los requisitos escribe la instrucción para Aria.");
                }
                executor.adjustRequirementsAsync(missionId, command.instruction().strip());
            }
            case REJECT -> {
                requirementsMemory.reject(missionId, version.version());
                memory.updateMission(missionId, MissionStatus.CANCELLED, 100, "Requisitos rechazados",
                        "El fundador rechazó los requisitos de Aria.");
                events.publish("EMPRESA_REQUIREMENTS_REJECTED", missionId, null, "human", Map.of("version", version.version()));
            }
        }
        return requirements(missionId).orElseThrow();
    }

    private static final Set<MissionStatus> STOPPED = Set.of(MissionStatus.AWAITING_INVESTOR, MissionStatus.COMPLETED,
            MissionStatus.FAILED);

    public RequirementsView buildIncrement(String missionId, int increment) {
        var mission = memory.find(missionId)
                .orElseThrow(() -> new IllegalArgumentException("No existe la misión " + missionId));
        var approved = requirementsMemory.approved(missionId)
                .orElseThrow(() -> new IllegalStateException("MISSION " + missionId + " no tiene requisitos aprobados."));
        var spec = jsonMapper.readValue(approved.specJson(), RequirementsSpec.class);
        if (!spec.incrementNumbers().contains(increment)) {
            throw new IllegalStateException("MISSION " + missionId + " no tiene incremento " + increment
                    + " (tiene " + spec.incrementNumbers() + ").");
        }
        var built = requirementsMemory.builtIncrement(missionId);
        if (increment != built + 1) {
            throw new IllegalStateException("El incremento " + increment + " va después del " + (increment - 1)
                    + "; el último construido es el " + built + ".");
        }
        if (!STOPPED.contains(mission.status())) {
            throw new IllegalStateException("MISSION " + missionId + " está en curso (" + mission.status() + ").");
        }
        requireAgentsOn(mission.teamId(), "construir el incremento " + increment + " de " + missionId);
        executor.buildIncrementAsync(missionId, increment);
        return requirements(missionId).orElseThrow();
    }

    /** Spec 2026-10-03 Aria §2: comandos de requisitos; van antes que la decisión del inversionista. */
    private static final Pattern SHOW_STORIES = Pattern.compile(
            "(?i)\\b(?:muestrame|mostrame|ver|dame|cuales son)\\s+(?:las\\s+)?(?:hu|historias|requisitos)\\b.*?(MISSION-[A-Za-z0-9-]+)");
    private static final Pattern APPROVE_STORIES = Pattern.compile(
            "(?i)\\b(?:apruebo|aprueba|aprobar)\\s+(?:las\\s+)?(?:hu|historias|requisitos)\\b.*?(MISSION-[A-Za-z0-9-]+)");
    private static final Pattern REJECT_STORIES = Pattern.compile(
            "(?i)\\b(?:rechazo|rechaza|rechazar)\\s+(?:las\\s+)?(?:hu|historias|requisitos)\\b.*?(MISSION-[A-Za-z0-9-]+)");
    private static final Pattern ADJUST_STORIES = Pattern.compile("(?i)^\\s*para\\s+(MISSION-[A-Za-z0-9-]+)\\s*:\\s*(.+)$",
            Pattern.DOTALL);
    private static final Pattern BUILD_INCREMENT = Pattern.compile(
            "(?i)\\bconstru(?:ye|ir|i)\\s+el\\s+incremento\\s+(\\d+)\\s+de\\s+(MISSION-[A-Za-z0-9-]+)");

    private String handleRequirements(String message) {
        var normalized = normalize(message);
        try {
            var build = BUILD_INCREMENT.matcher(normalized);
            if (build.find()) {
                var missionId = build.group(2).toUpperCase(Locale.ROOT);
                missionService.buildIncrement(missionId, Integer.parseInt(build.group(1)));
                return "Arrancó el incremento " + build.group(1) + " de " + missionId
                        + " sobre el mismo repositorio. Te aviso cuando termine.";
            }
            var show = SHOW_STORIES.matcher(normalized);
            if (show.find()) {
                var missionId = show.group(1).toUpperCase(Locale.ROOT);
                return missionService.requirements(missionId)
                        .filter(v -> v.version() != null)
                        .map(v -> "Requisitos de " + missionId + " (versión " + v.version() + ", " + v.versionStatus()
                                + "): " + v.summary())
                        .orElse(missionId + " no tiene requisitos de Aria.");
            }
            var approve = APPROVE_STORIES.matcher(normalized);
            if (approve.find()) {
                var missionId = approve.group(1).toUpperCase(Locale.ROOT);
                missionService.decideRequirements(missionId, new RequirementsDecisionCommand(
                        RequirementsDecisionCommand.RequirementsDecision.APPROVE, null));
                return "Requisitos de " + missionId + " aprobados: Neo planifica el incremento 1.";
            }
            var reject = REJECT_STORIES.matcher(normalized);
            if (reject.find()) {
                var missionId = reject.group(1).toUpperCase(Locale.ROOT);
                missionService.decideRequirements(missionId, new RequirementsDecisionCommand(
                        RequirementsDecisionCommand.RequirementsDecision.REJECT, null));
                return "Requisitos de " + missionId + " rechazados: la misión quedó cancelada.";
            }
            var adjust = ADJUST_STORIES.matcher(message);
            if (adjust.find()) {
                var missionId = adjust.group(1).toUpperCase(Locale.ROOT);
                missionService.decideRequirements(missionId, new RequirementsDecisionCommand(
                        RequirementsDecisionCommand.RequirementsDecision.ADJUST, adjust.group(2).strip()));
                return "Le pasé el ajuste a Aria; te aviso cuando las historias de " + missionId + " estén listas.";
            }
        } catch (IllegalStateException | IllegalArgumentException ex) {
            return "No se pudo: " + ex.getMessage();
        }
        return null;
    }
